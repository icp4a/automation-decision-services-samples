# Decision Intelligence Client Managed Software samples

These samples give you a working introduction to Decision Intelligence.

This repository has several branches. Refer to the one that corresponds to your version:
   - [**Master**](https://github.com/icp4a/automation-decision-services-samples/tree/master): Supports the latest version of Decision Intelligence.
   - [**26.0.0**](https://github.com/icp4a/automation-decision-services-samples/tree/26.0.0): Supports the 26.0.0 version of Decision Intelligence.
   - [**25.0.1**](https://github.com/icp4a/automation-decision-services-samples/tree/25.0.1): Supports the 25.0.1 version of Decision Intelligence.
   - [**25.0.0**](https://github.com/icp4a/automation-decision-services-samples/tree/25.0.0): Supports the 25.0.0 version of Decision Intelligence.
   - [**24.0.1**](https://github.com/icp4a/automation-decision-services-samples/tree/24.0.1): Supports the 24.0.1 version of Decision Intelligence.
   - [**24.0.0**](https://github.com/icp4a/automation-decision-services-samples/tree/24.0.0): Supports the 24.0.0 version of Decision Intelligence.

There are four main directories:

  - **Archives**: Decision services that you can run directly in a Decision Intelligence runtime.
  - **Decisionservices**: Decision services in compressed files that you can import directly into Decision Designer, the development environment in Decision Intelligence.
  - **Samples**: Tutorials and samples that you can use in Decision Intelligence. The tutorials provide
 detailed step-by-step instructions on specific features in Decision Intelligence, including Decision Designer and the external libraries. The samples provide code to use in Decision Intelligence.
  - **Practice**: Best practices for using Decision Intelligence.

To familiarize yourself with Decision Intelligence, start by following the tutorial `Getting started in Decision Intelligence`[![CP4BA](/resources/cloudpak4ba.svg "IBM Cloud Pak for Business Automation")](https://www.ibm.com/docs/en/cloud-paks/cp-biz-automation/26.0.0?topic=resources-getting-started)[![ADS](/resources/ads.svg "IBM Decision Intelligence Client Managed Software")](https://www.ibm.com/docs/en/dicms/26.0.0?topic=resources-getting-started).
